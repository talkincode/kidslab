# 初高中实验型互动课件规划
# Secondary School Interactive Lab Courseware Plan

> 适用学段：初中 `g7-g9`、高中 `g10-g12`。
> 课程顺序参考中国大陆通行的初高中知识结构，但不绑定单一教材版本；实现时仍需在各课件 `facts.md` 中逐条核对课程标准、教材边界和权威来源。
> 目标规模：**26 个课件**，其中 6 个存量课件纳入统一口径，新增 20 个；物理、化学、生物和数学均以“可操控、可测量、可记录、可推断”的实验闭环为主。

## 审计结论

- **结论：ACCEPT**
- **核心价值：** 当前小学规划已成体系，但初高中只有零散扩展课件。若继续按单个创意上新，主站虽能筛出初高中内容，却无法形成知识路径，也容易把“能拖动参数的动画”误当成实验。
- **现有结构可复用但不能直接承载完整目标：** 独立静态课件、双语主题、`facts.md`、构建校验和 E2E 基线都可沿用；缺少的是初高中独立状态清单、实验闭环合同、数据记录口径和覆盖矩阵。
- **主要风险：** 最大风险不是实现量，而是模型教错、实验与现实边界不清、随机噪声导致测试不可复现，以及复杂实验在手机上被压成难用的控制面板。

## 北极星：不是仿真动画，而是可完成的数字实验

每个课件至少完成一次以下闭环：

```text
提出问题 → 形成预测 → 只改变一个变量 → 观察/测量
    → 记录数据 → 图表比较 → 写出结论 → 用新情境验证
```

### 实验合同

1. **问题明确：** 首屏只有一个可行动的问题，不先给公式或结论。
2. **变量可辨：** 明确自变量、因变量和控制变量；改变多个变量时给出可恢复的提醒，而不是直接判错。
3. **测量有单位：** 仪器读数、量程、有效数字和单位一致；超量程、未调零、视差等只在对应课程确实教授时出现。
4. **数据可复现：** 同一参数与同一随机种子得到同一结果；测量噪声默认可关闭，不能用随机数掩盖模型错误。
5. **记录能推断：** 至少提供数据表或图像，学生要从数据关系得出结论，而不是做完操作后由系统朗读答案。
6. **模型有边界：** 明示“仿真测量”与现实实验的区别；近似公式写清适用范围，危险操作只在虚拟环境演示并给安全提示。
7. **自由与引导并存：** 引导任务保证 30 秒内开玩；完成后进入自由实验，不用答题锁住仪器。
8. **失败可恢复：** 接错、超量程、读数错误或变量失控后能原地修正，支持重置本次实验但不清空全部进度。

### 实验深度分级

| 等级 | 判定标准 | 用途 |
| --- | --- | --- |
| L1 观察 | 改变参数并观察现象 | 只适合作为概念引入，不单独算完整实验课件 |
| L2 对照 | 能保持控制变量，比较至少两组结果 | 初中入门最低要求 |
| L3 测量 | 有仪器、单位、数据表和图像，可由数据得出关系 | 本规划所有新增课件的最低要求 |
| L4 设计 | 学生自行选择器材、范围和步骤，系统校验方案是否能回答问题 | P0 课件至少提供一个 L4 挑战 |

## 元数据与分类决策

- 本轮不新增顶层 `biology` 分类。生物实验暂用 `category: "science"`，避免只为 2 个课件扩大主站分类、构建白名单、配色和测试面。
- 当独立生物实验达到 **6 个**，或用户数据表明初高中用户持续搜索“生物”却难以命中时，再把 `biology` 升为顶层分类。
- 新课件必须填写精确 `grades`，不得像部分存量课件一样留空。
- 实现前扩充 `src/taxonomy.json`。至少需要：运动、密度、力与摩擦、压强、浮力、欧姆定律、机械能、波与共振、电磁感应、质量守恒、气体制备、溶解度、反应速率、化学平衡、滴定、电化学、显微镜、细胞、酶、统计与抽样、动态几何。

## 技术与数据边界

1. **继续保持课件运行时独立。** 不让一个课件从另一个课件目录加载求解器；确需复用时，在源码阶段复制或由构建脚本内联，经各自测试后独立发布。
2. **先定义数据协议，不急着造通用框架。** 每个实验至少能表示：

   ```json
   {
     "version": 1,
     "seed": 42,
     "variables": {},
     "trials": [
       { "inputs": {}, "measurements": {}, "units": {}, "timestamp": 0 }
     ],
     "conclusion": ""
   }
   ```

3. **复杂模型分层。** 纯函数模型负责计算，渲染层只显示结果；参考解、单位、适用范围和误差容限写进单元测试与 `facts.md`。
4. **手机不压缩桌面面板。** 375×667 使用“器材 → 操作 → 数据 → 结论”分步页；桌面可同时显示实验台和记录区，两者共享同一实验状态。
5. **随机性可重放。** 测量误差、样本总体和粒子运动均使用显式种子；E2E 能加载固定种子重放同一次实验。
6. **不伪装现实精度。** 视觉粒子、颜色、模糊、烟雾和仪器动画如为教学示意，必须在 `facts.md` 和课件内轻提示中说明。

## 机器验收面

每个新增课件完成时至少具备：

1. **知识模型单测：** 用权威公式、参考表或解析解建立正常值、边界值和越界值；不能只测 UI。
2. **单位与精度测试：** 输入、显示、导出使用同一单位合同；近似值用显式容差，不比较格式化字符串。
3. **确定性重放：** 固定参数和 `seed` 后，数据表、图像关键点与结论判定一致。
4. **核心 E2E：** 桌面与手机各完成一次“预测 → 实验 → 记录 → 结论”Happy Path。
5. **失败与恢复 E2E：** 至少覆盖一种真实失败，如超量程、装置错误、变量未控制、错误读数或不适用模型，并验证原地修复。
6. **元数据与事实校验：** `grades` 非空，tags 来自 taxonomy，`facts.md` 的每条断言均有来源。
7. **人工验收：** 学科教师核对模型边界与表述；目标年级学生检查 30 秒上手、仪器可理解性和结论是否确由数据得出。视觉真实性、音效语义和课堂可用性不能由 smoke 测试替代。

## 完成定义

- 课件达到 L3 或以上，不是只有参数滑块和现象动画。
- 引导实验完整闭环可重复完成，自由实验不会因任意参数组合卡死。
- 知识模型、单位、公式、参考数据和适用范围通过自动化断言与人工学科复核。
- 中英双语、深浅主题、静音、桌面与手机交互满足 `AGENT.md`。
- `npm run build`、目标单元测试和目标 E2E 通过，`src/` 与 `courseware/` 同步。
