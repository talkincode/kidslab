## 产品语言

初中物理课是 **数字实验台**，不是闯关小游戏。

| 维度 | 小学 | 初中物理 |
|---|---|---|
| 孩子来干什么 | 玩起来，知识长在机制里 | 拧旋钮、读仪器、对照记录，自己看见规律 |
| 第一印象 | 角色、店铺、关卡 | 一眼能认出的仪器（天平、摆架、电表、光具座） |
| 文案 | 短句、图标、零术语优先 | 可以出现术语，但先用人话；不写说明书腔 |
| 反馈 | 对错服务游戏，失败可以好笑 | 对错只服务实验（超量程、接错线），不是考卷 |
| 成功时刻 | 「哇」的魔法瞬间 | 读数、对照表或图线自己长出关系 |
| 课标关系 | 覆盖重要直觉 | 年级与知识点可对上，但不做成同步练习册 |

硬性约束（与 `AGENTS.md` 初高中实验课壳一致）：

1. **观测 / 调试 / 实验。** 打开就能动手。禁止预测题、选择题、答对才能继续。
2. **全屏 three.js + 可收拢参数面板。** 手机改底部抽屉。禁止三栏说明书把舞台挤没。
3. **仪器必须像真的。** 孩子 1 秒内认出「这是什么」。
4. **BGM 与静音键。** 本地音频，首次手势后播放。
5. **模型可单测。** 公式、单位、边界、非法输入、失败恢复写在 `*-model.js`。

主站配合：选「初中」时问候语换成「来实验室，拧旋钮看变化」，并露出物理 / 化学分类；入口不隐藏、不标「建设中」。

## 试点课件（已上线，作为形态样本）

这两课满足「至少一个学科的初中规划 + 1～2 个试点」：一个是 issue 点名的存量课，一个是后来按实验合同新做的 L3 课。

| ID | 年级 | 孩子在干什么 | 状态 |
|---|---|---|---|
| `pendulum-lab` 单摆实验室 | `g8,g11` | 抓起摆球放手，调摆长 / 摆角 / 星球重力，对照 `T≈2π√(L/g)` | 已上线；补齐 `grades`。后续按实验合同补重复测量与拟合视图 |
| `density-detective-lab` 密度侦探实验室 | `g8` | 天平称重、量筒排水、读数入表，用 `m-V` 斜率认出铝 | 已上线 L3 观测闭环；形态标杆 |

同路径上已经能玩、用来验证「初中生吃这一套」的相邻课：`optics-lab`（`g8-g11`）、`motion-tracker-lab`（`g8,g10`）、`ohms-law-lab`（`g9,g11`）、`electric-mouse`（小学科学标签，纳入初中电学入口）。

## 初中物理学习路径（5～8 课试点规模）

只列初中主力年级 `g7-g9`。高中加深的同一主题（抛体、圆周、动量）放在 [`secondary-labs.md`](./secondary-labs.md) / [`secondary-labs-wave2.md`](./secondary-labs-wave2.md)，不在本表重复造课。

## 存量单摆的归属说明

`pendulum-lab` 曾经只出现在「已上线但不在小学规划 ID 内」。现归属：

- **学科路径：** 初中物理第 1 课（本文件）
- **实验规划：** [`secondary-labs.md`](./secondary-labs.md)「存量课件纳入」
- **学段标签：** `junior` + `senior`（小角度公式在高中仍成立，保留高中入口）
- **年级：** `g8,g11`
- **升级债：** 数据导出、重复测量、拟合视图；不另起 `simple-pendulum-lab`

## 非目标

- 不把小学物理直觉课（磁力冰球、小小金字塔）改标签充初中货架。
- 不把高中抛体 / 卫星 / 光电效应塞进本路径冒充初中。
- 不把单摆做成周期计算试卷。
- 本文件不新增独立目标计数；完成态仍勾在 [`status.md`](./status.md) 的初高中表里。
