> 本轮规模：**新增 20 个课件**。不改写、不替换第一轮 26 项（6 个存量 + 20 个新增），见 [`secondary-labs.md`](./secondary-labs.md)。

## 为什么还要一轮

第一轮把「可操控、可测量、可记录、可推断」的实验方法铺开了，物理和初中化学主干基本在路上。做成之后，初高中路径仍会在四处露白：

| 缺口 | 第一轮现状 | 若不补的后果 |
| --- | --- | --- |
| 初中数学函数与相似 | 只有平方根建筑师、动态几何 | 主站初中数学筛出来几乎没有「从数据到表达式」的课 |
| 高中数学主线 | 函数变形记偏参数滑块；抽样统计偏统计 | 三角、数列、导数、二次函数没有独立实验入口 |
| 内能与近代物理 | 机械能、波、电磁感应已规划 | 比热容、动量、圆周/卫星、变压器、光电效应缺席 |
| 结构与有机化学 | 速率、平衡、滴定、电化学已规划 | 原子/周期律、官能团、反应热、氧化还原本质缺席 |
| 生物学 | 显微镜 + 酶，共 2 个 | 光合、遗传、呼吸、DNA、生态系统无法形成路径 |

本轮目标不是再堆 20 个滑块动画，而是补上这些**知识路径空洞**，并保证每个课件的核心交互与第一轮不重复。

## 审计结论

- **结论：ACCEPT**
- **核心价值：** 第一轮验证实验合同；第二轮让初高中四个学科都能按课标走完一条可玩的主干，而不是物理偏科。
- **现有结构可复用：** 独立静态课件、双语主题、`facts.md`、L3 闭环、固定种子、构建校验和 E2E 基线全部沿用。
- **主要风险：** 数学课被做成「测量出定理」；生物课做成观察动画；光电效应 / 导数 / DNA 在手机上变成难用面板；与第一轮主题撞车（抛体 vs 二次函数、电化学 vs 氧化还原、酶 vs 光合）。

## 与第一轮的硬边界

1. **不重复 ID，不重复核心交互。** `function-grapher` 继续负责「已有解析式，拖参数看图像」；本轮函数课负责「从情境和数据构造表达式」。`projectile-motion-lab` 负责运动学分解；`quadratic-function-lab` 负责抛物线作为函数模型。`electrochemistry-lab` 负责原电池/电解池装置；`redox-electron-lab` 负责化合价与电子转移账本，不重做盐桥。`enzyme-kinetics-lab` 负责酶条件；`photosynthesis-lab` 负责光合速率。`plant-lab` / 规划中的 `plant-xray` 是小学生长观察，不计入本轮，也不用本轮光合课去勾选它们。
2. **数学不是物理。** 函数、三角、数列、导数的结论是必然关系，禁止用测量噪声、取平均或「实验证实了定理」来呈现。测量型数学（相似测高、勾股绳）可以有仪器和容差，但必须在 `facts.md` 写明：测得的是近似值，定理本身不是统计规律。归纳型数学沿用 [`primary-math-inquiry.md`](./primary-math-inquiry.md) 的实例表 + 反例/临界，深度目标 M3。
3. **生物仍用 `category: "science"`。** 第一轮 2 个 + 本轮 5 个 = 7 个独立生物实验，已越过「6 个升类」门槛。升类动作在**第 6 个生物课件开工时**同步改 `scripts/build.mjs`、主站配色和测试白名单；本规划不提前改分类，避免文档先于工程。
4. **实现顺序建议，不是铁律。** 第一轮剩余 P0 仍应优先（实验合同还差样本）。若要先填主站「数学/生物空洞」，允许把本轮 P0 的一次函数、二次函数、单位圆、光合、孟德尔与第一轮 P0 交错。不要先做本轮 P1 的光电效应 / DNA / 导数。

## 北极星（本轮补充）

每个课件仍然走第一轮闭环。数学归纳型把「测量」换成「构造实例」：

```text
提出问题 → 形成预测 → 只改一个变量 → 构造/测量多组实例
    → 记入不被清空的表 → 从表读出关系 → 学生先写结论
    → 系统才给名称或公式 → 用新情境验证或找临界
```

本轮 P0 必须提供一个 L4 挑战（自选范围/方案，系统只校验方案能否回答问题）。

### 1. 一次函数实验室 · Linear Function Lab — `linear-function-lab`

`g8` `math` `P0` `Canvas + DOM`｜义务教育数学 7–9 年级「函数」主题：一次函数的图像、斜率与截距、实际问题中的线性模型

- **核心问题：** 两个变化的量，怎样判断它们是一次函数关系？`k` 和 `b` 在具体情境里分别是什么？
- **玩法：** 三个站点共用一张「实例表」（自变量、因变量、预测、残差），表在站点之间不清空。① 水池注水：拖流速 `k` 与初始水位 `b`，水位随时间直线上升；先猜满池时刻再放水验证。② 两家出租车：起步价是 `b`、单价是 `k`，在同一张图上找交点——交点就是该换车的里程。③ 摄氏–华氏对照：已知若干标定点，学生自己读出 `F = 1.8C + 32`，系统在提交猜想前不显示公式。
- **自变量 / 因变量 / 控制变量：** 情境量（时间、里程、摄氏度） / 水位、车费、华氏度 / 每个站点只开放一个参数旋钮，其余锁定。
- **魔法时刻：** 两辆计价不同的车，费用线在某公里处交叉；交叉点一侧换车立刻更便宜。
- **模型边界：** 只覆盖 `y = kx + b`（`k ≠ 0`）。反比例、分段计价只作为「用残差看出不是一次函数」的对照，不展开教学。不把拟合残差解释成定理误差。
- **机器验收锚点：** 固定点列的斜率/截距解析解；两直线交点；学生提交前 DOM 中不得出现 `y=kx+b` 公式字符串；非直线对照的残差显著大于直线。
- **建议 tags：** 函数、实验

### 2. 二次函数喷泉 · Quadratic Fountain Lab — `quadratic-function-lab`

`g9,g10` `math` `P0` `Canvas`｜义务教育二次函数；高中「从函数观点看一元二次方程」

- **核心问题：** 开口、对称轴、顶点分别由什么决定？抛物线与 x 轴交点为什么就是方程的根？
- **玩法：** 公园喷泉要穿过三个高度环。学生调 `a`（开口）、顶点横坐标 `h`、高度 `k`，水柱是 `y = a(x-h)² + k`。实例表记录 `(a,h,k)` 与是否过环、与地面交点。第二站：已知三个落点，反推顶点；第三站：把抛物线当成利润曲线，读出最高点，再把「利润为 0」的两点标成方程的根。公式名称在学生提交「对称轴是什么」之后才出现。
- **自变量 / 因变量 / 控制变量：** `a,h,k` 或三个落点 / 过环、零点、最大值 / 每站只改一类量。
- **魔法时刻：** 对称轴两侧同样高度的环被同一股水同时穿过；把对称轴挪开，一边进环一边空。
- **模型边界：** 只处理实系数、开口非零的二次函数。不进入复数根。不与 `projectile-motion-lab` 共用运动学分解；喷泉是函数图像，不是受力分析。
- **机器验收锚点：** 顶点、对称轴、判别式与零点个数的 golden cases；过三点唯一抛物线；提交猜想前无「顶点公式」文案。
- **建议 tags：** 函数、实验

### 3. 单位圆正弦实验室 · Unit Circle Lab — `unit-circle-lab`

`g10,g11` `math` `P0` `Canvas`｜高中必修「三角函数」：弧度、单位圆、正弦/余弦作为圆上点的投影

- **核心问题：** 正弦波上的一个高度，对应圆上的哪个点？周期、振幅、相位分别改的是圆的哪件事？
- **玩法：** 左侧单位圆上有一个动点，右侧同步画出「高度–角度」曲线。学生先只改角度，看高度如何涨落；再改半径（振幅）、转速（周期）、起始角（相位）。实例表至少 8 行：角度、高度、余弦（水平投影）。L4：给定 `y = A sin(ωt + φ)` 的目标波，只用圆上的三个旋钮去对齐，禁止直接填公式系数。
- **自变量 / 因变量 / 控制变量：** 角度或 `A,ω,φ` / 纵投影、横投影、波形 / 每次只解锁一个旋钮。
- **魔法时刻：** 圆上的点刚好转完一圈，右侧正弦正好铺满一个完整周期，首尾高度咬合。
- **模型边界：** 默认单位圆；半径可改为振幅演示，但 `facts.md` 须写明教科书定义在单位圆上。不覆盖解三角方程、诱导公式全集。角度用弧度为主，可切换度数并标明换算。
- **机器验收锚点：** `sin,cos` 与投影一致，周期 `T=2π/ω`；相位平移与起始角一致；固定 `t` 序列与 `Math.sin` 容差比较。
- **建议 tags：** 函数、圆、实验

### 4. 动量碰撞实验室 · Momentum Collision Lab — `momentum-collision-lab`

`g11` `physics` `P0` `Canvas`｜高中选择性必修 1「动量与动量守恒定律」：一维碰撞、弹性与非弹性

- **核心问题：** 碰撞前后什么量守恒、什么量不守恒？质量比如何决定碰后速度？
- **玩法：** 气垫导轨 + 光电门。学生称质量、读碰前碰后速度（必须手动对准光门读数，不可自动填表）。三组对照：等质量弹性对心、质量比 1:2 弹性、粘性碰撞（完全非弹性）。数据表计算 `p` 与 `E_k`。L4：设计一次「碰后一车停下」的质量–速度组合并验证。
- **自变量 / 因变量 / 控制变量：** `m1,m2,v1,v2`、碰撞类型 / 碰后速度、动量和、动能和 / 导轨水平、一维、无摩擦（可开摩擦作为越界对照）。
- **魔法时刻：** 轻车高速撞停重车，重车几乎不动、轻车原速弹回；两车对撞后粘在一起，按质量比慢悠悠滑向重的一边。
- **模型边界：** 只保证一维、水平、两体。摩擦导轨下动量不守恒要明示系统选取（含地球）。弹性用恢复系数 `e=1`，完全非弹性 `e=0`；不进入二维斜碰。
- **机器验收锚点：** 弹性与非弹性解析解；动量守恒（无摩擦）与动能是否守恒的布尔判定；错误光门读数被拒绝且不入表。
- **建议 tags：** 实验、重力（可加「动量」到 taxonomy）

### 5. 比热容实验室 · Specific Heat Lab — `specific-heat-lab`

`g9` `physics` `P0` `Canvas + DOM`｜义务教育物理「内能」：比热容、`Q = cmΔT`、水和沙升温差异

- **核心问题：** 同样加热，为什么有的物质烫得快？`c` 到底是哪根曲线的斜率？
- **玩法：** 相同电热丝功率，三杯等质量的水、沙、食用油。学生读温度计（模拟液柱，需估读到最小刻度的一半），记 `t–θ` 表，算 `c = Pt / (mΔθ)`。对照：改质量、改功率，看斜率如何变。L4：给定未知液体的升温曲线，鉴定它更接近水还是油。
- **自变量 / 因变量 / 控制变量：** 物质、质量、功率、加热时间 / 温度 / 每组只改一个；容器散热默认可关闭。
- **魔法时刻：** 水和沙同时加热，沙的温度线先竖起来，手（热警告）已经烫，水还在慢慢爬。
- **模型边界：** 忽略相变；到沸点锁定温度并提示「本课不进入汽化」。散热开启时能量守恒要计入损失项，默认关闭以保证可复现。比热容用课标常用值（水 `4.2×10³ J/(kg·°C)`），写明是参考值不是测量定义。
- **机器验收锚点：** 固定 `P,m,c,t` 的 `Δθ` golden cases；单位 `J,kg,°C`；超量程温度计拒读。
- **建议 tags：** 实验、物质三态（实现前应增「比热容」「内能」）

### 6. 原子与周期律实验室 · Atomic Periodic Lab — `atomic-periodic-lab`

`g10` `chemistry` `P0` `DOM`｜高中必修「原子结构与元素周期律」：1–20 号电子排布、半径与金属性递变

- **核心问题：** 核电荷数增加时，原子半径、金属性、最外层电子数怎样周期性重复？
- **玩法：** 把电子拖进能级格，生成 1–20 号原子结构示意图。右侧周期表只点亮已构建的元素。对照实验：同周期（Na–Ar）与同主族（Li/Na/K 或 F/Cl）的第一电离能、原子半径柱状图由模型给出，学生先预测再揭晓。L4：给出未知元素的半径与金属性线索，推断它在表中的位置。
- **自变量 / 因变量 / 控制变量：** 原子序数、电子填入顺序 / 结构示意图、半径、电离能趋势 / 一次只比较一条周期或一个主族。
- **魔法时刻：** 按核电荷数排开，金属性在某一步突然变弱、非金属性抬头，周期表的台阶自己长出来。
- **模型边界：** 只到 20 号；能级按课标示意图（K/L/M），不进入 4s/3d 争议。电离能与半径用教学参考趋势，不伪装成实验测量值。惰性气体「难反应」用高电离能表示，不做反应动画。
- **机器验收锚点：** 1–20 号电子排布表；同周期半径总体减小、同主族半径增大的单调断言；错误填入（先填外层）被拒绝。
- **建议 tags：** 实验（实现前应增「原子结构」「元素周期律」）

### 7. 光合作用实验室 · Photosynthesis Lab — `photosynthesis-lab`

`g8,g10` `science` `P0` `Canvas`｜义务教育生物学植物的生活；高中必修「细胞的能量供应」中的光合

- **核心问题：** 光、二氧化碳、温度里，哪一个才是当前的限制因素？绿光为什么几乎不干活？
- **玩法：** 金鱼藻在试管里释放氧气泡。学生用计数器（或固定时长截图）测气泡速率。对照：光强、与光源距离、滤色片（红/蓝/绿）、CO₂ 浓度（碳酸氢钠）、温度。数据表画速率曲线。淀粉检测是延时站：遮光叶片 vs 见光叶片的碘液颜色。L4：设计一组对照证明「绿光不是好光源」，必须包含等光强的红或蓝对照。
- **自变量 / 因变量 / 控制变量：** 光强、波长、CO₂、温度 / 气泡速率、淀粉染色 / 每组只改一个；植物种类与叶片面积锁定。
- **魔法时刻：** 挡住红蓝光，气泡骤减；换绿光、光强再大，气泡几乎不长。
- **模型边界：** 气泡法测的是净氧释放，不是瞬时真光合。光补偿点以下气泡可为 0 或微负（溶解氧），不把 0 解释成「植物死亡」。色素吸收光谱用教学简化峰，不伪装成分光光度计精度。不替代 `plant-lab` 的多日生长。
- **机器验收锚点：** 速率对光强的饱和曲线；绿光组显著低于红/蓝（等光子通量）；固定种子下同参数同气泡序列；对照缺失时 L4 校验失败。
- **建议 tags：** 光合作用、植物、实验

### 8. 孟德尔豌豆园 · Mendel Garden Lab — `mendel-garden-lab`

`g8,g12` `science` `P0` `DOM + Canvas`｜义务教育「遗传与变异」；高中必修「遗传与进化」分离定律

- **核心问题：** 子二代为什么不是 1:1，而会靠近 3:1？一次实验偏离 3:1，是定律错了还是样本太小？
- **玩法：** 选择亲本（纯合黄/绿、高/矮），得到 F1，再自交得 F2。植株按固定种子伪随机萌发，性状可点计。频率表**逐代累积**，禁止覆盖式重跑。并排显示：本组株数、累计株数、理论 3:1。第二站：测交 1:1。L4：学生自己选样本容量，系统问「你现在敢不敢下结论」，小样本不得给出「定律成立」的判定。
- **自变量 / 因变量 / 控制变量：** 亲本基因型、样本容量 / 性状比例 / 环境一律无关（本课不讲环境饰变）。
- **魔法时刻：** F2 从几十株晃到几百株，黄绿比从乱跳慢慢锁进 3:1 的带子里。
- **模型边界：** 只讲完全显性、独立遗传的单因子或两对独立因子（9:3:3:1 作为 L4）。不进入连锁、不完全显性、致死。随机用显式种子，同种子同亲本同出苗序列。3:1 是理论比例，样本频率只是趋近。
- **机器验收锚点：** 纯合亲本 F1 全为显性；测交期望 1:1；固定种子下株数与性状计数可复现；小样本不得自动判定「符合 3:1」。
- **建议 tags：** 生态、实验（实现前应增「遗传」）

### 9. 有机分子工坊 · Organic Builder Lab — `organic-builder-lab`

`g10,g12` `chemistry` `P0` `three.js`｜高中必修「简单的有机化合物」；选必可加深到同分异构

- **核心问题：** 碳为什么能搭出那么多种分子？官能团换一个，反应为什么全变？
- **玩法：** 球棍拼装台。必做：甲烷（正四面体）、乙烯（平面双键）、乙醇、乙酸。拼完用「试剂喷瓶」做教学反应：乙烯褪溴水、乙醇被氧化、乙酸与乙醇酯化（条件提示浓硫酸、加热）。对照墙：C₄H₁₀ 的正丁烷 vs 异丁烷，性质卡轻微分叉。L4：只给分子式 C₂H₆O，拼出乙醇与甲醚两种同分异构，系统用连通性校验，不看摆放角度。

- **魔法时刻：** 六个碳既能排成直链也能排成环，旁边两张性质卡立刻分成两种物质。
- **模型边界：** 键角用教学理想值。反应是官能团示意，不给出产率或机理每步。苯的结构用课标允许的表示，不陷入凯库勒争论。禁止拼出本课未教的爆炸性组合还显示「真实爆炸」。
- **机器验收锚点：** 甲烷四键等效、乙烯平面、乙醇/乙酸官能团识别、C₂H₆O 两种连通异构的图同构判定。

### 10. 切线斜率实验室 · Derivative Slope Lab — `derivative-slope-lab`

`g12` `math` `P0` `Canvas`｜高中选择性必修「导数」：平均变化率、瞬时变化率、切线

- **核心问题：** 割线越收越短的时候，斜率在逼近什么？这个数为什么可以叫瞬时速度？
- **玩法：** 一条可切换的 `s–t` 曲线（二次、三次）。学生先在曲线上钉两个点看割线斜率（平均速度），再把第二点滑向第一点，斜率稳定到一个数。实例表记录 `Δt` 与割线斜率，至少 6 行递减 `Δt`。第二站：把切线斜率画成新的 `v–t` 高度，学生自己说出「斜率表就是速度表」。系统在学生提交「瞬时变化率」猜想之前，不出现「导数」一词。L4：找曲线上斜率为 0 的点，并解释它在原运动里是什么（最高点/回头）。
- **自变量 / 因变量 / 控制变量：** 点的位置、`Δt`、曲线类型 / 割线斜率、切线斜率 / 一次只动一个点。
- **魔法时刻：** `Δt` 收到几乎看不见，割线贴住曲线变成切线；同时右侧速度针停在一个稳定读数上。
- **模型边界：** 只用多项式，避免数值抖动被当成「导数不存在」。不讲极限符号的 ε-δ。不把数值逼近说成导数的定义本身；`facts.md` 写明这是几何与运动直觉，形式定义在课堂。
- **机器验收锚点：** 二次 `s=t²` 在 `t=1` 的导数 2；表中 `|Δt|` 递减时斜率单调逼近；提交前无「导数」文案。
- **建议 tags：** 函数、实验（实现前应增「导数」）

### 11. 相似测高实验室 · Similar Measure Lab — `similar-measure-lab`

`g9` `math` `P1` `Canvas`｜义务教育「图形的变化」：相似、相似比；勾股定理作为第二站

- **核心问题：** 为什么一根短杆的影子，能算出树有多高？3-4-5 的绳子为什么能得到直角？
- **玩法：** ① 同一时刻竖杆与树的影子，测杆长、杆影、树影，算树高；把太阳高度角改掉，比值不变、影长变。② 泰勒斯截线：平行线截三角形两边成比例。③ 勾股绳：12 节绳按 3-4-5 围直角，再故意围 3-4-6 看直角消失。测量有估读容差，但结论区必须区分「测得约 4.9 m」与「相似比相等是必然」。
- **魔法时刻：** 太阳挪了，影子全变，树高的计算结果却还停在同一个数上。
- **机器验收锚点：** 相似比与树高解析解；3-4-5 为直角、3-4-6 不是；容差只作用于读数，不作用于定理判定。

### 13. 圆周与卫星实验室 · Circular Orbit Lab — `circular-orbit-lab`

`g11` `physics` `P1` `three.js` 或 `Canvas`｜高中必修「曲线运动与万有引力」：匀速圆周、向心加速度、环绕与逃逸

- **核心问题：** 速度差一点点，卫星为什么有的坠回、有的圆轨、有的飞走？
- **玩法：** 在指定高度发射，调水平速度。叠加重力与所需向心力的矢量。记录周期、半径。对照：近地圆轨、椭圆（教学示意）、逃逸。L4：给定周期求轨道半径。
- **魔法时刻：** 速度刚够，轨迹从坠回大气变成闭合椭圆，再高一点被甩成双曲线飞出屏幕。
- **模型边界：** 中心引力、质点、忽略大气与三体。椭圆用开普勒教学示意，不要求在本课推导面积定律。逃逸速度用 `v=√(2GM/r)`，写明相对圆轨 `√2` 倍。
- **机器验收锚点：** 圆轨 `v=√(GM/r)`、周期、逃逸速度；低于圆轨阈值坠入。

### 14. 变压器实验室 · Transformer AC Lab — `transformer-ac-lab`

`g11` `physics` `P1` `Canvas`｜高中选择性必修「电磁感应及其应用」：交变电流、变压器

- **核心问题：** 匝数比改变时，电压和电流谁升谁降？为什么能高压输电？
- **玩法：** 原副线圈匝数可调，示波器看正弦电压。接灯泡当负载，读电压表/电流表（量程自选）。理想变压器 `U1/U2=n1/n2`，`I1/I2=n2/n1`。对照：空载、短路保护。L4：给定输电距离与损耗预算，选匝数比。

- **模型边界：** 默认理想变压器；铜损可开但须标明。不进入磁滞细节。交流有效值与峰值关系 `√2` 要可关可开。

### 15. 光电效应实验室 · Photoelectric Lab — `photoelectric-lab`

`g12` `physics` `P1` `Canvas`｜高中选择性必修 3「波粒二象性」：光电效应、爱因斯坦方程

- **核心问题：** 光更亮和光更紫，哪一个才能打出电子？遏止电压在量什么？
- **玩法：** 选择波长（或色光）与强度，打到金属上。电流表、遏止电压旋钮。表记：有无光电流、饱和电流、遏止电压。对照：红光再亮也没有电流；紫光再弱也有（强度只改电子数目）。L4：换金属（不同逸出功），测截止频率。
- **魔法时刻：** 把红光亮度拉满，电流仍是零；换成很暗的紫光，电流立刻跳起。
- **模型边界：** 用爱因斯坦方程 `E_k = hν - W`。不进入半导体能带。普朗克常量用课标值，写明是输入常量不是本实验「测出」的历史过程（可在 L4 用斜率估 h，并给误差带）。
- **机器验收锚点：** 阈值频率与逸出功；饱和电流随强度、不随频率（超过阈值时）；遏止电压随频率、不随强度。
- **建议 tags：** 光学、实验（实现前应增「光电效应」）

### 16. 反应热实验室 · Thermochemistry Lab — `thermochemistry-lab`

`g10,g11` `chemistry` `P1` `DOM + Canvas`｜高中必修「化学反应与能量转化」；选必可定量到盖斯定律

- **核心问题：** 反应热能不能用两条弯路加出来？量热计测到的温度变化怎么变成 `ΔH`？
- **玩法：** 咖啡杯量热计：已知比热与质量，测 `ΔT`，算 `Q`。三步盖斯循环：路径 A 直达，路径 B+C 绕行，代数和相等。粒子视图只示意断键吸热、成键放热，不给精确键能表除非 L4。
- **魔法时刻：** 两条完全不同的反应路径，热效应加总后落在同一格。
- **模型边界：** 恒压近似 `Q_p ≈ ΔH`。忽略量热计本身热容或单独给出其水当量。不进入吉布斯自由能。
- **机器验收锚点：** `Q=cmΔT`；盖斯循环代数和；吸放热符号约定。
- **建议 tags：** 实验（实现前应增「反应热」）

- **核心问题：** 化合价升高的那个原子，电子到底去哪儿了？升降的数目为什么必须相等？
- **玩法：** 把 `Zn + CuSO4`、`H2 + CuO`、`Fe + CuSO4` 写成「电子账本」：左侧失电子、右侧得电子，数目对不上就不能过账。微观层显示电子从锌粒飞向铜离子，宏观层析出铜红色。不出现盐桥和闭合回路——那是 `electrochemistry-lab` 的装置课。

### 18. 细胞呼吸实验室 · Cell Respiration Lab — `cell-respiration-lab`

`g10` `science` `P1` `Canvas`｜高中必修「细胞的能量供应」：有氧呼吸与无氧呼吸

- **核心问题：** 氧气耗尽的那一刻，产物和曲线为什么一起拐弯？
- **玩法：** 酵母+葡萄糖。开口装置 vs 密封装置。测 CO₂（气泡或石灰水浑浊程度）与酒精检测（教学试纸）。温度对照。数据表：时间、CO₂ 速率、氧气余量。氧气归零后密封组转无氧，速率下降、酒精阳性。

- **机器验收锚点：** 有氧阶段速率高于无氧；密封组出现酒精标志；开口组不出现；温度对酶活性的非单调（可与酶课共用趋势但不共用代码）。
