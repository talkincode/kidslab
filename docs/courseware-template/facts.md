# my-course 知识断言

## 适用范围

- 覆盖竖直方向、地面水平、重力加速度恒定、忽略空气阻力的弹跳观测。
- 恢复系数 e 取 0 到 1；质量只改变能量读数，不改变轨迹。
- 不覆盖斜面、滚动、形变过程、空气阻力或变重力场。

## 知识断言

- [F1] 从静止释放、下落高度为 h、重力加速度为 g 时，落到地面的时间 t = √(2h/g)，落地速率 v = √(2gh)。[S1]
- [F2] 取地面为重力势能零点时，机械能 E = (1/2)mv² + mgh。[S1][S2]
- [F3] 碰撞前后法向速率之比 e（恢复系数）恒定时，忽略空气阻力的下一次最大高度满足 h′ = h e²；e = 1 时机械能守恒并回到原高度，e = 0 时不再弹起。[S2][S3]
