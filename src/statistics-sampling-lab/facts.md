# statistics-sampling-lab 知识断言

## 适用范围

- 覆盖有限总体的简单随机抽样（不放回）、按规模比例分层抽样、整群抽样（随机抽取 1–2 栋住宅楼并对楼内全部居民做普查）和便利抽样（只调查市中心街角调查点附近的人）。
- 总体是课件内的「星河城」：N = 400 名居民，四区各 100 人，每区 5 栋住宅楼、每栋 20 人。个人属性是每周通勤时间（分钟）。四区均值固定为 12、24、36、48，全市均值精确为 30。楼内通勤时间是混合的，楼与楼之间均值有适度差别。这是教学用合成总体，不是真实城市调查。界面标明被估计量是平均通勤用时（单位 min），并用四区地名标签标出各区均值，便于把整群抽到的楼与样本均数对上。
- 样本标准差用无偏公式 s = √[Σ(xᵢ − x̄)² / (n − 1)]。简单随机抽样的标准误使用有限总体校正：SE = (s/√n) · √[(N − n)/(N − 1)]。
- 约 95% 区间写成 x̄ ± 1.96 SE，这是 n 较大、近似正态时的常用区间，不是精确的 t 区间，也不覆盖非概率抽样的真实覆盖率。
- Bias(x̄) = E(x̄) − μ。单次抽样的 x̄ − μ 只表示「这一次差多远」，不是偏倚。普查给出 μ 之后，才展示该方法的理论偏倚；若已做 k = 50/100 次重复抽样，再给出蒙特卡洛偏倚。
- 三维城市、发光小人与液晶读数是示意；测量噪声默认关闭，同一种子、方法、n 与抽次得到同一批人。批量重复抽样只更新抽样分布图，不按次重绘三维场景。对错反馈只服务空记录、重复记录和非法样本量，不是考卷。
- 不覆盖系统抽样、PPS、复杂分层标准误的完整公式、假设检验或贝叶斯推断。整群抽样在本课不是「先抽 1 个街区再在该街区内抽 n 人」。

## 知识断言

- [F1] 有限总体均值 μ = (1/N) Σ xᵢ。本课合成总体 N = 400，四区人数相等且区均值分别为 12、24、36、48 分钟，因此 μ = 30 分钟精确成立。总体标准差 σ = √[Σ(xᵢ − μ)² / N] = √188 分钟。[S1][S4]
- [F2] 简单随机抽样（不放回）使每个大小为 n 的子集被抽到的概率相同。此时样本均值 x̄ 是 μ 的无偏估计：E[x̄] = μ，故 Bias(x̄) = 0。[S1][S2]
- [F3] 按规模比例分层时，第 h 层抽取 nₕ = n · (Nₕ / N) 人，再把各层样本合并。各层人数相等时即每层 n/4 人。层内相对同质、层间异质。该估计量对 μ 仍无偏，并且通常比同样 n 的简单随机抽样更稳。[S1][S2]
- [F4] 整群抽样先随机抽取 1–2 个群（本课的群是住宅楼），再对该楼全部居民做普查。楼内通勤时间混合（群内异质），楼与楼之间均值有适度差别。等容量整群的 x̄ 对 μ 无偏，但抽样分布通常比同样 n 的简单随机抽样更散。[S1][S2]
- [F5] 便利抽样只调查容易碰到的人。本课调查点设在市中心街角，样本全部来自该点附近，E[x̄] = 12 分钟，Bias(x̄) = 12 − 30 = −18 分钟。重复抽很多份便利样本，均值会挤在 12 附近，看起来很稳，却稳定地估错全市均值。[S2][S3]
- [F6] 样本标准差 s = √[Σ(xᵢ − x̄)² / (n − 1)]，n ≥ 2，单位与观测值相同（分钟）。这是总体标准差的常用无偏估计，不把 n 放在分母。[S1]
- [F7] 不放回简单随机抽样的均值标准误为 SE = (s/√n) · √[(N − n)/(N − 1)]，N > n ≥ 2。当 n 接近 N 时校正项变小；n = N 时 SE = 0（普查）。界面与本断言均使用该有限总体校正形式，而不是无放回忽略时的 s/√n。[S1]
- [F8] 在近似正态且 n 不太小时，x̄ ± 1.96 SE 是约 95% 的置信区间。便利抽样的区间可以很窄，却常常装不进 μ：精度高不等于没有偏倚。[S1][S3]
- [F9] 把同一种方法重复抽 k 次得到的 x̄ 画成点图，就是该统计量的抽样分布。简单随机抽样的点堆在 μ 附近；分层抽样更窄；便利抽样稳定偏离 μ；整群抽样中心仍近 μ 但更散。增大 n 时，无偏方法的分布会按大约 1/√n 收紧。[S1][S2]
