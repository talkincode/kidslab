# projectile-motion-lab 知识断言

## 适用范围

- 覆盖忽略空气阻力、重力加速度恒定、地面水平的二维抛体运动。坐标系：水平向右为 +x，竖直向上为 +y，地面 y = 0，抛出点在 (0, h)。
- 重力加速度默认 g = 9.80 m/s²，课件允许在 1.60–24.8 m/s² 之间调节，用来对照不同重力，不代表变重力场或科里奥利力。
- 初速度 v₀、抛射角 θ 从水平面量起；θ = 0° 是平抛，v₀ = 0 是自由落体。运动分解为互相独立的水平匀速和竖直匀变速。
- 数值轨迹用恒定加速度的运动学步进（含 ½ a Δt² 项），与解析解逐点比较；测量噪声默认关闭，同一参数得到同一读数。
- 三维大炮、铁环、草地和球体是示意，不模拟旋转、Magnus 效应、空气阻力或地面弹跳。对错反馈只服务超量程参数、尚未落地就记录、飞行中重复发射，不是考卷。
- 不覆盖斜面抛体、有阻力弹道、相对论或三维侧向风偏。

## 知识断言

- [F1] 忽略空气阻力时，水平方向加速度为 0，竖直方向加速度为 −g（向上为正）。水平分运动是匀速直线运动，竖直分运动是匀变速直线运动，两者独立，互不影响。[S1][S2]
- [F2] 以抛出时刻为 t = 0，水平位置 x(t) = v₀ cosθ · t，水平速度 vx 保持为 v₀ cosθ。公式在 ax = 0 且取同一水平正方向时成立，单位为 m 与 m/s。[S1][S3]
- [F3] 竖直位置 y(t) = h + v₀ sinθ · t − (1/2) g t²，竖直速度 vy(t) = v₀ sinθ − g t。g 取正值，单位为 m/s²；公式只在 ay = −g 恒定、地面以上（y ≥ 0）时使用。[S1][S3]
- [F4] 落到 y = 0 的飞行时间 T 满足 (1/2) g T² − (v₀ sinθ) T − h = 0，取正根 T = [v₀ sinθ + √((v₀ sinθ)² + 2 g h)] / g。h = 0 且 θ > 0 时退化为 T = 2 v₀ sinθ / g。[S1][S3]
- [F5] 从同一高度 h 同时释放的平抛（θ = 0°，v₀ > 0）与自由落体（v₀ = 0）落地时间相同，均为 T = √(2h/g)，与水平初速度无关。这是水平与竖直分运动相互独立的直接推论。[S2][S4]
- [F6] 水平射程 R = vx · T。当 h = 0 时，R = v₀² sin(2θ) / g；θ = 45° 时 sin(2θ) = 1，射程最大。[S1][S3]
- [F7] 若初速度竖直分量 vy₀ > 0，最高点出现在 t = vy₀ / g，高度 H = h + vy₀² / (2g)；若 vy₀ ≤ 0（平抛或下抛），最高点就是抛出点高度 h。[S1][S3]
