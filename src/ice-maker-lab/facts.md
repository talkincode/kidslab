# ice-maker-lab 知识断言

## 适用范围

- 面向小学高年级到初中的蒸汽压缩式制冰/制冷教学模型；展示压缩机、冷凝器、节流阀、蒸发器的闭环与热量迁移方向。
- 课件中的温度、压力、结冰速度、房间升温均为简化示意量，不对应真实设备的精确读数、COP 或具体冷媒牌号。
- 不讨论吸收式制冷、热电制冷、真实冷媒选型、安全充注或电气控制细节。

## 知识断言

- [F1] 常见家用制冰机/冰箱的制冷核心是蒸汽压缩循环：冷媒在闭合回路中反复压缩、冷凝、节流、蒸发，把热量从冷处搬到热处。[S1][S2]
- [F2] 蒸发器内低压液态冷媒吸热汽化；吸走的热来自模盒里的水（或箱内空气），使水温下降并在 0 °C 附近凝固成冰。[S1][S3]
- [F3] 压缩机对冷媒蒸汽做功，提高其压力和温度，使冷媒能在比室温更高的条件下向环境放热。[S1][S2]
- [F4] 冷凝器中高压气态冷媒向房间空气放热并液化；因此制冰时机器背后/侧面会变热，房间会获得被搬走的热以及压缩机输入的功转化的热。[S1][S2]
- [F5] 节流装置（毛细管或膨胀阀）降低液态冷媒压力，使其温度下降，为下一轮在蒸发器吸热做准备。[S1]
- [F6] 在标准大气压附近，纯水在约 0 °C 发生液–固相变；结冰需要持续带走潜热，不是“温度一到 0 °C 就立刻全部变成冰”。[S3][S4]
- [F7] 打开箱门会让较暖的房间空气进入，增加需搬走的热量，从而减慢结冰；这是边界条件变化，不是制冷原理失效。[S1]
