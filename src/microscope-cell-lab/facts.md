# microscope-cell-lab 知识断言

## 适用范围

- 覆盖初中生物学常用的复式显微镜：固定 10× 目镜，4× / 10× / 40× 物镜，视野数 FN = 18 mm。
- 视野直径按标本面公式 d = FN / M_物镜 计算；总放大倍数 = 目镜倍数 × 物镜倍数。课件用同一公式，不含变倍目镜、相差、油镜或数码变焦。
- 焦深随物镜增大而变窄，是教学用分段值（4× 约 80 μm、10× 约 20 μm、40× 约 4 μm），用来锁死「低倍粗准焦、高倍只准细准焦」的操作顺序，不是某台真实显微镜的出厂焦深。
- 植物装片按洋葱鳞片内表皮细胞的教学尺寸：长约 200 μm、有细胞壁与中央大液泡、细胞核偏一侧、无叶绿体。动物装片按口腔上皮细胞：直径约 50 μm、无细胞壁、无叶绿体、无中央大液泡、细胞核大致居中。
- 三维显微镜外形、光线颜色和细胞填色是示意，不代表真实折射率、染色剂或衍射极限。测量噪声默认关闭，同一参数得到同一读数。
- 不覆盖油镜、细菌、细胞分裂过程、组织切片制作，也不把显微镜当考试卷：对错反馈只服务调焦、光线和装片安全。

## 知识断言

- [F1] 复式显微镜的总放大倍数等于目镜放大倍数与物镜放大倍数的乘积；本课目镜固定 10×，因此 4×、10×、40× 物镜对应总放大倍数 40×、100×、400×。[S1][S2]
- [F2] 标本面视野直径 d（mm）= 目镜视野数 FN / 物镜放大倍数。本课 FN = 18 mm，故 4×、10×、40× 物镜的视野直径分别为 4.50 mm、1.80 mm、0.45 mm。[S3][S4]
- [F3] 在目镜与视野数不变时，视野直径与物镜放大倍数成反比：把物镜从 4× 换到 10×，视野直径变为原来的 4/10；再换到 40×，变为 10× 时的 10/40。[S3][S4]
- [F4] 若沿视野直径方向大约能数出 N 个首尾相接的细胞，则细胞平均长度 ≈ d / N。换算时 1 mm = 1000 μm。[S2][S4]
- [F5] 规范操作是先用低倍物镜（4×）配合粗准焦螺旋找到清晰物像，再换中倍或高倍，并且高倍（40×）只准使用细准焦螺旋，避免压碎装片。[S1][S2]
- [F6] 洋葱鳞片内表皮细胞有细胞壁和中央大液泡，细胞核常被挤到一侧，通常观察不到叶绿体；口腔上皮细胞没有细胞壁和叶绿体，也没有中央大液泡，细胞核大致位于细胞中央。这些结构差异只有在焦点附近、光线合适时才能从视野中读出。[S1][S5]
