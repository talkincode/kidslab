# circular-orbit-lab 知识断言

## 适用范围

- 只覆盖「地球中心引力场 + 单个质点卫星」的二体问题：忽略大气阻力、太阳和月球的引力、地球形状与质量分布的不均匀、卫星自身质量对地球的影响，也不涉及变轨点火与姿态控制。
- 发射一律是在某高度沿水平（垂直于地心连线）方向给一个速度，因此发射点必然是轨道的一个拱点；课件不处理带仰角的发射与倾斜轨道，所有轨道都在赤道平面内。
- 椭圆与双曲线轨迹是按课标教学示意画出的圆锥曲线，不是真实发射任务的轨道设计结果；「坠回」判定为近地点低于海拔 100 km，这是教学阈值，不代表真实再入走廊。
- 数据表里的周期是对同一条解析轨道做固定步长数值积分测得的，与解析周期的偏差在 0.01% 以内；同步轨道判定容差为周期相差不超过 1%。
- 三维画面里的地球贴图、云层、星空和地面站标记只是装饰，位置不代表真实地理；时间是压缩显示的，画面上的「倍速」标签给出压缩倍数。

## 知识断言

- [F1] 万有引力常量取 G = 6.674×10⁻¹¹ N·m²/kg²，地球质量取 M = 5.972×10²⁴ kg，地球平均半径取 R = 6.371×10⁶ m；课件中出现的高度都是相对地球表面的高度，轨道半径 r = R + h。[S3] [S4]
- [F2] 卫星做半径为 r 的匀速圆周运动时，万有引力提供全部向心力：GMm/r² = mv²/r，故环绕速度 v = √(GM/r)，与卫星质量无关。[S1]
- [F3] 圆轨道周期 T = 2πr/v = 2π√(r³/GM)；轨道半径越大，环绕速度越小而周期越长。[S1] [S2]
- [F4] 由周期反求圆轨道半径 r = (GM·T²/4π²)^(1/3)。取一个恒星日 T = 86164 s，得 r ≈ 4.216×10⁷ m，对应高度约 3.58×10⁴ km，这就是地球同步轨道。[S1] [S2] [S4]
- [F5] 在半径 r 处的逃逸速度 v = √(2GM/r)，正好是同一半径处环绕速度的 √2 倍；达到或超过该速度时卫星不再返回。[S1]
- [F6] 单位质量的机械能 ε = v²/2 − GM/r 决定轨道类型：ε < 0 为椭圆（含圆）、ε = 0 为抛物线、ε > 0 为双曲线；椭圆的半长轴 a = −GM/(2ε)。[S1] [S2]
- [F7] 水平发射时轨道偏心率 e = |r·v²/GM − 1|：速度等于环绕速度时 e = 0 得到圆，速度大于环绕速度时发射点是近地点，小于时发射点是远地点。[S1] [S2]
- [F8] 椭圆轨道两个拱点满足 r近 + r远 = 2a；水平发射速度略小于环绕速度时，近地点会降到地面以下，卫星因此坠回。[S2]
- [F9] 开普勒第二定律（角动量守恒）给出 r²·dθ/dt = 常量，因此同一椭圆上卫星在近地点跑得快、在远地点跑得慢。[S2]
- [F10] 圆轨道周期等于地球自转周期（一个恒星日）时，卫星相对地面静止，始终位于同一地点上方，这是通信与气象卫星使用同步轨道的原因。[S1] [S4]
