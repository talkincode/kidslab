# shape-tailor 知识断言

## 适用范围

- 课件覆盖小学五年级平面图形面积：平行四边形、三角形、梯形，通过割补转化成长方形或平行四边形后再求面积。
- 底、高均为正数；课件示例使用整数边长与整数高，面积结果为正整数。
- 不讨论圆、扇形、曲面或三维表面积；不引入坐标系解析几何。

## 知识断言

- [F1] 平行四边形的面积等于底乘以对应高：\(S = a \times h\)。把一条高一侧的直角三角形裁下并平移到对边，可拼成与原平行四边形等底等高的长方形，面积不变。[S1]
- [F2] 三角形的面积等于底乘以对应高再除以 2：\(S = \dfrac{1}{2} a h\)。两个全等三角形可拼成一个平行四边形，该平行四边形面积是三角形的 2 倍。[S1]
- [F3] 梯形的面积等于上底与下底之和的一半乘以高：\(S = \dfrac{(a + b)}{2} \times h\)。沿一条高裁拼后，可转化成与原梯形等高、底为 \(\dfrac{a+b}{2}\) 的长方形/平行四边形，面积不变。[S1]
- [F4] 割补转化不改变面积：裁下的部分平移或旋转后拼回，各部分面积之和等于原图形面积，因此转化后的长方形（或平行四边形）面积就是原图形面积。[S1]

## 来源

- [S1] 中华人民共和国教育部，《义务教育数学课程标准（2022 年版）》，第二学段“图形与几何”中关于多边形面积的探索与公式；人民教育出版社《义务教育教科书·数学》五年级上册“多边形的面积”单元（平行四边形、三角形、梯形的面积推导）。
