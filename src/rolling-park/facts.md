# rolling-park 知识断言

## 适用范围

- 面向小学六年级「圆的认识」：半径、直径、周长、圆周率与圆面积。数值一律用十进制近似，不涉及弧度制、弧长公式，也不讨论 π 的无理性。
- A 模式把「车轮滚一圈画出的颜料线」当作周长的实物模型，前提是纯滚动不打滑；课件不模拟摩擦、形变与滑移，方轮动画只用于对比滚动是否平稳，不参与任何数值结论。
- A 模式的猜想环节接受 2.9–3.3 之间的读数，用来容纳「3」「3.1」「3.14」等不同精度的口头估计，不是对 π 的精确值判定。
- B 模式把圆等分成有限片扇形、交错拼成近似长方形，是面积公式的直观表征，不是极限意义下的证明：片数越多越接近长方形，但任何有限片数都不严格等于长方形。
- C 模式统一取 3.14 作为 π 的近似值，答案允许约 ±0.35 米的误差，不考察精确计算。

## 知识断言

- [F1] 圆的周长是圆的周界长度；对任意圆，周长与直径之比都是同一个常数 π，即 C = πd。[S1]
- [F2] 圆的直径是半径的 2 倍（d = 2r），因此周长也可写作 C = 2πr。[S1]
- [F3] 圆的面积 A = πr²，其中 r 是半径。[S1]
- [F4] 小学阶段用 3.14 或 22/7 近似 π；使用计算器的 π 键会得到略有差异的结果，因为它保留了更多小数位。[S1]
